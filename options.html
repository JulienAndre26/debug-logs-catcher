Debug Logs Catcher — Options

Expert capture settings. Changes apply to the next captured events — no restart needed.

How deep console objects are expanded (range 0–8). 0 = shallow preview only. 1 (default) = one level plus a free preview of nested objects — one CDP call per logged object. Higher values fully expand nested objects but issue many more CDP calls and can lag on chatty pages (arrays of objects fan out).

Request/response bodies larger than this are truncated (not dropped), flagged with responseBodyTruncated / postDataTruncated. Default 200 ko, max 1000 ko. Bodies are captured only for XHR/Fetch calls and only for data types (JSON, XML, text/plain, form-encoded, GraphQL); page assets (HTML/CSS/JS, images, fonts, media) are skipped (responseBodyOmitted: "resource-type" / "non-text"). multipart/form-data request bodies are parsed down to their text fields (postDataFields); file uploads are dropped. Secret-bearing fields (password, token, …) are masked on export.
